# Cooperative Training – Generative AI & LLM Engineering

## Overview

This repository showcases the practical work completed during my cooperative training at the **Umm Al-Qura University Deanship of Information Technology and E-Learning**, focusing on Generative AI and Large Language Models (LLMs).

Throughout the training, I completed a series of hands-on implementations and experiments covering transformer architectures, attention mechanisms, pretraining and instruction tuning concepts, prompt engineering, OpenAI API integration, AI-powered web application development, and educational content generation.

The repository documents my practical learning journey, with each module building upon the previous one and culminating in the development of the final project, **AI-Powered Educational Course Generator**, which is available in a dedicated repository.
